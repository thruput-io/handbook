— The agent **MUST NOT** read or load handbook rules (`RULES.md`, `PHILOSOPHY.md`,`WORKFLOW.md`, `CODE_REVIEW.md`, `GIT_HUB.md`) from the current active workspace directory
(`/Users/Shared/workspace/handbook` or relative path `./`). 17 - Handbook rules and guidelines must only be sourced from
